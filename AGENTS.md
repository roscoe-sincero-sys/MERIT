# MERIT project instructions

The user prefers autonomous execution and automatic approval review for this project.

- For implementation, fix, or build requests, complete the assigned work through appropriate validation. Inspect the relevant code, make in-scope changes, run the necessary checks, and address failures caused by those changes without asking for permission at each step.
- Make routine implementation decisions using the request, repository conventions, and available evidence. State material assumptions and continue useful independent work when clarification is pending.
- Persist until the assigned outcome is complete or an essential dependency, missing decision, or required approval prevents further progress. Do not stop at a plan or ask whether to continue work already authorized.
- Keep review, explanation, and planning requests within their requested scope. Autonomous execution does not turn a review into an instruction to implement its findings.
- Preserve unrelated user changes. Give concise progress updates and report the result, validation performed, and any remaining limitations.
- Honor authorization already established in the conversation. Ask only for essential information or approval that is actually required; explain the specific reason when asking.
- Use the project's automatic approval reviewer for eligible approval requests, as configured in `.codex/config.toml`. Follow the active sandbox, permission, and managed approval requirements. Obtain authorization for destructive or external changes when the user's request has not already established it.
