MERIT USER GUIDE

Importing NPI and CLIA records

How to load laboratories, ordering facilities and providers into MERIT's reporter registry from a spreadsheet, check the file before anything is saved, fix the rows MERIT cannot load, and clear the results that were waiting for them.

In one minute
  1. Open Reporters → Import NPI and CLIA records and download the CSV template.
  2. Fill in one row per laboratory, facility or provider: its type, name, and its CLIA number or NPI.
  3. Click Check the file. Nothing is saved yet: MERIT lists the ready rows and explains every row it cannot load.
  4. Click Import. Ready rows are added, or update the entry with the same CLIA number or NPI.
  5. Fix the other rows and check again. Then release any results held as unknown sender.

Who can import: people with the Edit the reporter registry permission (intake clerks, supervisors and administrators). Everyone who can see people can search the registry. A practice file, sourceCode/samples/registry_npi_clia_sample.csv, comes with MERIT.

Companion guide: MERIT User Guide - Daily Operations. Interactive diagram: docs/npi-clia-import_workflow.html.

1. What the reporter registry is for

Every blood test result in MERIT names the laboratory that ran it and, usually, the facility and provider who ordered it. The reporter registry is MERIT's list of them, each identified by a national number:

KindExamplesIdentified byWhy MERIT needs it
LaboratoryA reference laboratory, a hospital laboratoryCLIA number (required); NPI optionalIntake links every result to its laboratory by CLIA number. A result from a laboratory that is not registered is held as unknown sender.
FacilityA pediatric practice, a clinic, a hospital, a health centerNPI (organization) or CLIA numberShows who ordered the test, for follow-up calls and the reporter timeliness report.
ProviderA physician, nurse practitioner or physician assistantNPI (individual)Links the ordering provider on each result, for confirmatory test and prenatal notifications.

2. NPI and CLIA numbers in brief

NPI: National Provider Identifier

1245319599

  • 10 digits, no letters.
  • The last digit is a check digit. One wrong or swapped digit almost always fails it, so MERIT catches most typing mistakes.
  • Individuals and organizations each have their own NPI.
  • Look one up in the national NPPES NPI Registry (npiregistry.cms.hhs.gov).

CLIA number

21D0123456

  • Two digits, the letter D, then seven digits: ten characters.
  • Issued by CMS to every laboratory that tests human specimens.
  • Laboratories print it on their reports; you can also look it up with CMS's CLIA laboratory search.
  • Providers do not have CLIA numbers.

MERIT ignores spaces and hyphens in both (21D-0123456 and 1245 319 599 are accepted) and accepts a lower-case d.

3. Prepare the file

  1. Open Reporters and click Import NPI and CLIA records.
  2. Click Download the CSV template. It has the column names and one example of each kind.
  3. Open it in Excel or another spreadsheet. Replace the examples with your rows: one row per laboratory, facility or provider.
  4. Save as CSV (in Excel: File → Save As → CSV UTF-8 (Comma delimited)). Keep the first line, the column names, unchanged.

Spreadsheet tips. Keep NPIs as plain 10-digit numbers: if Excel shows 1.24532E+09, widen the column or format it as Text before saving. Do not add total rows, notes or extra header lines. Up to 5,000 rows and 2 MB per file; split bigger lists.

4. Check the file

  1. On the import page, under Choose the file, click Choose File and pick your CSV.
  2. Click Check the file. Nothing is saved yet.
  3. Read the summary: how many rows are ready (by kind) and how many need attention. Each row that needs attention is listed with its line number in the file and what to fix.

5. Import

  1. When the ready rows look right, click Import n ready row(s).
  2. MERIT shows how many entries were added and how many updated, and lists the rows it did not load.
  3. Fix those rows in your spreadsheet. Save, then check and import the file again. Rows already loaded are simply updated again, so re-importing the whole file is safe.

How MERIT decides "add" or "update"

  • Laboratories and facilities are matched on their CLIA number first, then their NPI. A match is updated with the new name and phone; otherwise a new entry is added.
  • Providers are matched on their NPI.
  • Blank cells never erase what is stored. To remove a phone number or end a reporter, ask your administrator.
The check is valid for 30 minutes. If you wait longer, MERIT asks you to check the file again before importing. That way the rows imported are always the rows you just reviewed.

6. After the import: release the held results

Results that arrived before their laboratory was registered are waiting on Held records with the cause unknown sender.

  1. Open Held records and click the Unknown sender group for that laboratory.
  2. Tick the rows (or the box at the top of the table for all of them) and click Release selected.
  3. MERIT checks them again. Now that the laboratory is known they load, or wait for another cause such as match review.

To confirm an entry, search for it on Reporters by name, CLIA number or NPI.

7. Adding or correcting one entry

For a single new laboratory or a corrected name you do not need a file.

  1. Open Reporters and search for the reporter first.
  2. Under Add or correct one entry, choose the Kind and fill in the name and identifiers.
  3. Click Save entry. The same rules apply as for a file: identifiers are checked, and an entry with the same CLIA number or NPI is updated.

8. Good practice

  • Register a laboratory before its first file arrives when a new laboratory starts reporting. Ask your administrator to set up its intake profile at the same time.
  • Once a month, open Reports → Reporter timeliness and completeness to find reporters that send late or leave fields blank.
  • Keep one master spreadsheet of your reporters and re-import it after big changes, such as a hospital system merger. Re-importing updates; it never duplicates.
  • Use the names people recognize, for example "Harbor Pediatrics - Dundalk" for one branch of a practice.

9. Common questions

I imported the same file twice. Do I now have duplicates?
No. The second import updated the entries the first one added.

A laboratory has two CLIA numbers (two sites).
Register each site as its own laboratory row, with its own CLIA number and a name that tells them apart.

The NPI is right but MERIT says the check digit is wrong.
Check for a dropped or extra digit, or a cell that the spreadsheet changed (scientific notation, removed leading characters). Copy it again from the NPPES NPI Registry.

Can I import people's test results this way?
No. This import is only for reporters. Results come in on Intake (see the Daily Operations guide).

The Import button is missing.
Your role or profile does not include Edit the reporter registry. Ask your supervisor or administrator.
