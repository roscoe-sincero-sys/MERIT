# Security reports: the complete walkthrough

Use MERIT's security reports as a county security officer, a state administrator and a platform investigator.
All examples use synthetic training data. Duration: approximately 9 minutes 46 seconds.

- [Narrated video with captions drawn into the picture](security-reports.captioned.mp4)

| Start | Chapter |
|---|---|
| 0:00 | Choose the right scope and review access |
| 1:25 | Investigate all sign-in patterns |
| 3:02 | Trace views, changes and exports in the audit log |
| 4:32 | Understand screen usage and reconstruct a session |
| 6:29 | Administrator: investigate one account |
| 7:23 | Platform investigator: unknown user names |
| 8:53 | Follow up and preserve the review trail |

The walkthrough covers every security report and report export, including matching and nonmatching name lookups,
temporary name reveal, and returning to hashes. Scope, retention, missing telemetry, paging and export limits are
explained on the relevant screens. Volume-dependent and unavailable-key outcomes are explained rather than staged.

See the [coverage and rebuild guide](../../../training/docs/security-reports.md) for the complete use-case mapping,
synthetic fixtures, and validation commands. A human training review is still needed before official publication.
